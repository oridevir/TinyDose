# בדיקות אוטומטיות — TinyDose

שתי בדיקות שמריצות את האתר בדפדפן אוטומטי (Playwright) **על הקבצים שבתיקייה**, בלי לגעת באתר החי ובלי לגעת במאגר האמיתי.

**להריץ אחרי כל שינוי בחישוב, בדף החישוב או במסך הניהול — לפני העלאה.**

## 1. תרחישי חישוב — `calculator-scenarios.mjs`

```
node tests/calculator-scenarios.mjs
```

- מייצר כ-290 תרחישים (אקראיים קבועים + מקרי קצה) ומחשב לכל אחד את התשובה הנכונה **באופן עצמאי**.
- משווה לבועה, לפירוט החישוב, להודעת הוואטסאפ, לתדפיס ולחלונית עיגול המנה.
- בודק כללים קבועים: אף פעם מעל המקסימום היומי · טווח שרק קצהו העליון חורג — מוגבל · חריגה מלאה — חסום · אין NaN / undefined · טווחים עם בידוד LTR · שינוי שדה מבטל עיגול · איפוס · סליידר · שמירת הערות להורים.
- תוצאה תקינה: `FAILURES: 0`. כל כשל מודפס עם נתוני התרחיש.
- סט אקראי אחר / גדול יותר: `SEED=987 N=600 node tests/calculator-scenarios.mjs`
- בדיקת גרסה אחרת של האתר (למשל ישנה): `ROOT=/path/to/site node tests/calculator-scenarios.mjs`

## 2. מסך הניהול — `admin-flows.mjs`

```
npm install --prefix tests @supabase/supabase-js@2
node tests/admin-flows.mjs
```

- הפקודה הראשונה — פעם אחת בלבד: עותק מקומי של ספריית Supabase (בסביבת הענן `cdn.jsdelivr.net` חסום). התיקייה `tests/node_modules` לא נשמרת בריפו.
- מאגר **מדומה בזיכרון** — שום דבר לא נכתב למאגר האמיתי.
- עובר על המסלולים בטלפון ובמחשב: אימות + רשימת בדיקה, הוספה עם העתקת מינון, תרופה וסירופ חדשים, אזהרת כפילות, שכפול לאבחנה אחרת, מחיקה, Enter לשדה הבא, תצוגה מקדימה עם התראות; וגם שדף החישוב ו-`admin-old.html` נטענים.
- תוצאה תקינה: `ERRORS []` בסוף.

> שתי הבדיקות מחפשות Playwright מותקן, ואם אין — את ההתקנה הקיימת בסביבת הענן.
